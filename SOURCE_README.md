# R-460 Poseidon 1.5.3 source

This ZIP is a snapshot of the mod's editable files, not a Blueprinter Export Source ZIP. Copy the Assets and Runtime paths into an existing Blueprinter Unity project with matching game placeholders. Keep the .meta files with their assets so Unity retains the references.

The archive does not contain the game's _donotship placeholders or Nuclear Option assemblies. Set up the Blueprinter project and game references before opening the prefabs or building a package.

The TEL runtime plugin is in Runtime/PoseidonTELRuntime. Its project expects the game DLLs at the path set in PoseidonTELRuntime.csproj; change GameDir for another installation.
