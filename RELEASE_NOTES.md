# R-460 Poseidon 1.5.0

Adds twin missile mounts for Medusa, Alkyon, and Darkreach, plus the separate R-460N tactical nuclear Poseidon (1.5 kt). All three missile variants now perform a pronounced terminal pop-up before diving on the target. The nuclear round costs 34 million and has slightly improved armor and durability. Aircraft-launched Poseidons have a corrected encyclopedia speed estimate near 1,800 km/h.

Install `R-460 Poseidon_1.5.0.nobp` and `PoseidonTELRuntime.dll` together. Remove older Poseidon `.nobp` files before installing. Nuclear Option 0.34.2, BepInEx, and NOBlueprinter are required.

Asset wiring and package contents have been checked. Twin launch behavior, nuclear blast radius, and terminal pop-up still need live mission verification.
