# R-460 Poseidon 1.4.0

This release adds the stock AShM1 VLS booster assembly to the ground-launched R-460. Its model, launch sound, fire, smoke, and trail use game assets. The booster burns for five seconds and separates before the cruise motor starts. Both missile variants now use the stock cruise motor particle effect.

The missile's unit definition is now classified as a missile and has the standard missile icons. This corrects the target identity used by air-defense systems; its radar size was not increased.

The TEL continues to engage detected enemy ships within 108 km through the included runtime plugin. The user confirmed the updated mod works in game.

Install `R-460 Poseidon_1.4.0.nobp` and `PoseidonTELRuntime.dll` together. Remove older Poseidon `.nobp` files before installing. Nuclear Option 0.34.2, BepInEx, and NOBlueprinter are required.
